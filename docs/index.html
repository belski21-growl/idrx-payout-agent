IDRX Payout Agent — Live Demo

An agent that receives USD₸, converts it to IDRX (Indonesian rupiah stablecoin) on Textile FX, and pays the IDRX out to a named recipient — all on Celo mainnet (chain 42220), with an ERC-8021 attribution tag on every transaction and an ERC-8004 on-chain identity.

Built for the Celo “Agents Open for Business” hackathon (Loops House), track Stablecoin Corridors. Submission deadline: 7 Dec 2026, 09:00 GMT (16:00 WIB).

How it works

  1. Check USD₸ / CELO / IDRX balances (public RPC read).
  2. Preview a Textile RFQ quote for USD₸ → IDRX (free, no key, no signature).
  3. Request a firm quote — keyless, with a free EIP-712 “Textile Taker Control” proof.
  4. Approve USD₸ to the Textile reactor (once, only the shortfall).
  5. Submit the swap — broadcasts transactions.swap exactly as returned.
  6. Transfer all IDRX received to the named recipient.
  7. Write an evidence JSON file with the quote, tx hashes, blocks, amounts, and fees.

Every transaction carries the ERC-8021 attribution suffix for code celo_41b8d909dcde (plus the Loops House code celo_e94fe5d67772 when set).

Try it yourself

git clone https://github.com/belski21-growl/idrx-payout-agent.git
cd idrx-payout-agent
npm install
npm test                                   # unit tests (offline, no key)
node agent/idrx-payout-agent.mjs --dry-run # preview quote + plan, sends nothing

A live payout run needs a funded work wallet (≥ $1.00 USD₸, the Textile floor) and the key via env var only — see the README. No live run is triggered from this page.
